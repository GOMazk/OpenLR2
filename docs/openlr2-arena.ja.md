# OpenLR2 Arena

Arena は OpenLR2 のマルチプレイです。譜面と乱数シードを共有し、グラフ／ゲーム内ペースメーカーでライブスコアを見ます。IR が対応していれば部屋の結果も残せます。

セッションごとにオーバーレイの **Connection**（`Insert`）でモードを選びます。

| モード | やること |
|---|---|
| **IR (CustomIR)** | Arena 対応 CustomIR を `display_ir` にしてログインし、IR からもらった **room id** で **Join room**。OpenLR2 自体は部屋を作りません。 |
| **LAN** | 1 台が **Start server**、他は username + ホスト IP で **Connect**（ポート **2222**）。Username / host は記憶されます。 |

人数上限は OpenLR2 の固定値ではなく、**IR モジュール／サーバ**（または LAN ホスト側）が決めます。

## はじめ方

### IR

1. Arena 対応 CustomIR を `LR2files/CustomIRs/` に入れる。
2. `openlr2-config.xml` の `display_ir` をそのフォルダ名にする。
3. いつもどおり IR にログインする。
4. IR 側で部屋を作る／開き、**room id** を控える。
5. ゲームで `Insert` → room id 入力 → **Join room**。

### LAN

1. ホスト PC: `Insert` → **LAN** → **Start server**。
2. 全員: **Username** と **Server IP / hostname** → **Connect**。
3. 同じ LAN／VPN で OK。通信は `ws://host:2222`。

曲の途中で切断すると同期は止まりトーストが出ますが、**ローカルプレイは続きます**。退出するときは **Leave**。

## オーバーレイ

移動できるロビー／チャット／スコア窓。位置は `LR2files/Config/imgui.ini`、設定・キーは `LR2files/Config/arena.ini` に保存。

| 操作 | 既定 |
|---|---|
| ロビー開閉 | `Insert` |
| スコア／グラフ窓 | `Page Up`（または Settings） |
| チャット送信 | **Send** または Enter |
| アイテムモード | Lobby Settings または `F4` |
| ロビー表示中のゲーム入力ミュート | Settings — **既定 ON** |
| キー変更 | Settings → Bindings |
| ojama 使用 | **Backspace**（アイテムモード時） |
| Give host / Kick（ホスト） | ロビーでプレイヤーを右クリック |

- ミュート **ON**（既定）: ロビー表示中はゲームキーが効かない。
- ミュート **OFF**: ロビーを開いたまま選曲／プレイ可。チャット／room／LAN 入力中はキーボードがオーバーレイに取られる。
- オーバーレイの文字入力は **IME 非対応**（ラテン／貼り付け／UTF-8 表示は可）。
- オーバーレイが一切出ないときは、通常の描画経路でない環境（例: ソフトウェアレンダリング）の可能性があります。Arena は普段どおりのハードウェア描画が必要です。

## プレイの流れ

1. **ホスト**が先に譜面を選ぶと、ハッシュと乱数シードが共有される。
2. 全員が同じ譜面をローカルに持つ必要あり（MD5、`song.db`）。無い人はロビーで通知され ready できない。
3. 読み込み後、全員 ready になるまで待って同時スタート。
4. プレイ中、スコアはグラフ／ペースメーカーにだいたい秒間 10 回更新。
5. 曲終了後:
   - **IR:** ソロと同じ規則で IR ランキング送信（ojama でも止めない）。部屋履歴は IR が対応しているときだけ。
   - **LAN:** ピアの final スコアのみ（遠隔の部屋アーカイブなし）。

`LR2files/Config/sample_*` のスキンプレビュー譜面は部屋選曲として送りません。

## ojama

ホストが Settings / `F4` でオン。コンボでアイテムを貯め（2×／3× で強化）、**Backspace** で相手に投げる（約 8 秒効果）。**Item settings** で重み／閾値を変えられ、他の人にも同期されます。

## ペースメーカー

ゲーム内ペースメーカーの目標は部屋の **相手の最高 EX**。スコア窓には全員が出ます。

## 補足

- **IR:** 通信は CustomIR 経由（P2P ではない）。OpenLR2 経由で公網 IP は相手に見えません。
- **LAN:** LAN／VPN のポート **2222**。CustomIR とは別です。
- オーバーレイ直後の初回 Join／Connect は一瞬止まることがあります。
- ライブ同期はスコア／グラフ／ペースメーカーのみ（相手ノートレーンのライブ表示なし）。
