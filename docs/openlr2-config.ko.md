# openlr2-config.xml

[English](openlr2-config.md) | 한국어 | [简体中文](openlr2-config.zh-Hans.md) | [日本語](openlr2-config.ja.md)

이 파일은 OpenLR2만 쓰는 설정입니다. 기존 LR2 설정 파일 옆에 있습니다.

`LR2files/Config/openlr2-config.xml`

`LR2files/Config/config.xml`은 원래 LR2 옵션용으로 그대로 쓰입니다. 이 문서의 옵션은 `openlr2-config.xml`에서만 읽습니다.

## 고치기 전에

- 게임을 끈 다음 고치세요. 게임을 종료하면 이 파일을 다시 저장해서, 직접 고친 내용이 덮어씌워질 수 있습니다.
- 이 파일이 없어도 게임은 아래 기본값으로 켜집니다. 정상 종료하면 파일이 만들어집니다. 파일은 있는데 XML을 읽지 못하면 `Failed to read OpenLR2 config`를 띄우고 시작하지 않습니다.
- 따로 적지 않은 경우 `0`은 끄기, `1`은 켜기입니다.
- 해당 줄이 없으면 아래에 적은 기본값을 씁니다.
- 태그 이름은 바꾸지 마세요. 태그 사이의 값만 바꾸면 됩니다.
- 이 파일의 글자 코드는 Shift_JIS입니다. 경로에 한글, 한자, 일본어가 있으면 게임 안에서 고른 뒤 종료해서 저장하는 편이 안전합니다.

## system

### resolution

스킨이 자기 크기를 적지 않았을 때의 화면 크기입니다. 스킨 파일에 `#RESOLUTION`이 있으면 그 화면은 스킨에 적힌 크기를 쓰고, 이 값은 그때의 기본 크기입니다.

| 값 | 크기 | 이름 |
| --- | --- | --- |
| 0 | 640×480 | SD |
| 1 | 1280×720 | HD |
| 2 | 1920×1080 | Full HD |

1과 2가 아닌 숫자는 화면을 640×480으로 엽니다. 파일에 적은 숫자는 0으로 바꾸지 않고, 게임을 종료해도 그 숫자가 그대로 다시 저장됩니다. SD 크기는 숫자를 픽셀로 바꿀 때만 씁니다. `1`은 1280×720, `2`는 1920×1080, 그 외는 모두 640×480입니다.

### fullscreenfilter

화면을 키울 때 그림을 어떻게 부드럽게 할지 정합니다.

| 값 | 모습 |
| --- | --- |
| 0 | 부드럽게 (bilinear) |
| 1 | 픽셀을 날카롭게 (nearest) |
| 2 | CRT |

### fullscreenfitstretch

그림 비율과 모니터 비율이 다를 때의 처리입니다.

| 값 | 결과 |
| --- | --- |
| 0 | 그림 비율을 유지합니다. 옆이나 위아래에 여백이 생길 수 있습니다. |
| 1 | 화면을 가득 채우도록 늘립니다. 가로세로가 늘어나 보일 수 있습니다. |

### screenmode

게임을 어떤 창으로 열지 정합니다. `config.xml`의 `screenmode`는 쓰지 않습니다. OpenLR2는 이 파일의 `screenmode`를 씁니다.

| 값 | 결과 |
| --- | --- |
| 0 | 전체 화면 |
| 1 | 창 모드 |
| 2 | 테두리 없는 전체 화면 (모니터를 덮는 창) |

파일을 읽을 때 0보다 작거나 2보다 큰 숫자는 메모리에서 0으로 바꿉니다. 정상 종료하면 파일에도 `0`이 저장됩니다. `0`은 모니터의 현재 모드로 여는 전체 화면입니다. `1`은 창입니다. `2`는 테두리 없이 모니터를 덮는 창입니다. `0`과 `2`는 둘 다 전체 화면이고, 전체 화면 방식만 다릅니다. 이 치환은 파일을 읽을 때 일어나고, 창 모드를 적용하기 전입니다. 창 모드를 적용하는 함수는 범위 밖 숫자를 테두리 없는 전체 화면으로 보지만, 이 파일에서 읽은 값은 그 함수에 범위 밖인 채로 전달되지 않습니다.

## play

### gaugeautoshift

게이지 자동 변경(GAS)입니다. 선곡 화면의 옵션에서도 켤 수 있고, 그 선택은 여기에 저장됩니다.

| 값 | 결과 |
| --- | --- |
| 0 | 끔. 고른 게이지를 유지합니다. |
| 1 | 켬. 그 게이지로는 실패할 상황이면, 아직 클리어 중인 더 쉬운 게이지로 바꿉니다. |

G-ATTACK은 바꾸지 않습니다.

### newrandomrestart

결과 화면에서 흰 키와 파란 키를 함께 누르고 있으면 곡을 다시 시작합니다. 그때 노트 순서를 어떻게 할지를 정합니다.

| 값 | 결과 |
| --- | --- |
| 0 | 노트 순서는 그대로입니다. |
| 1 | 2번 키(파란 노트)는 노트를 다시 섞습니다. 다른 파란 키는 같은 순서를 유지합니다. |

플레이 도중 재시작(Start와 Select를 같이 누른 뒤, Start는 새 순서, Select는 같은 순서)과는 관계없습니다.

이 줄이 없으면 기본값은 0(끔)입니다.

### lifttype

리프트를 켜고 끕니다. 리프트는 노트와 판정선을 위로 올립니다. 판정 시간은 바뀌지 않습니다.

| 값 | 결과 |
| --- | --- |
| 0 | 끔. 아래 `lift` 숫자는 적용되지 않습니다. |
| 1 | 켬. |

0이 아닌 숫자는 모두 1로 처리합니다. 1P와 2P는 시작할 때 같은 설정을 씁니다.

### lift

노트와 판정선을 얼마나 올릴지입니다. 0부터 100까지입니다. 0은 원래 위치, 100은 가장 위입니다. 보이는 위치만 바뀝니다.

1P와 2P는 이 숫자로 시작합니다. 배틀에서는 플레이 중에 양쪽을 따로 바꿀 수 있지만, 다음 실행 때 기억하는 값은 1P 숫자뿐입니다.

## skin

### courseresult

코스 결과 화면에 쓸 스킨 파일 경로입니다. 선곡, 플레이, 일반 결과 같은 다른 스킨은 `config.xml`에 있습니다. 원래 LR2에는 이 스킨 칸이 없어서 OpenLR2가 여기에 둡니다.

아직 고르지 않았다면 비워 두세요.

## network

### display_ir

선곡 화면과 결과 화면에 보여줄 인터넷 랭킹 이름입니다. `LR2files/CustomIRs` 안의 폴더 이름과 같아야 합니다.

비워 두면 원래 LR2 랭킹 표시를 유지합니다. 폴더 이름과 맞지 않으면 그 랭킹은 나오지 않습니다.

## 예시

```xml
<?xml version="1.0" encoding="shift_jis"?>
<config>
	<system>
		<resolution>0</resolution>
		<fullscreenfilter>0</fullscreenfilter>
		<fullscreenfitstretch>0</fullscreenfitstretch>
		<screenmode>1</screenmode>
	</system>
	<play>
		<gaugeautoshift>0</gaugeautoshift>
		<newrandomrestart>0</newrandomrestart>
		<lifttype>0</lifttype>
		<lift>0</lift>
	</play>
	<skin>
		<courseresult></courseresult>
	</skin>
	<network>
		<display_ir></display_ir>
	</network>
</config>
```
