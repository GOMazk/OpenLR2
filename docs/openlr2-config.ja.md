# openlr2-config.xml

[English](openlr2-config.md) | [한국어](openlr2-config.ko.md) | [简体中文](openlr2-config.zh-Hans.md) | 日本語

このファイルは OpenLR2 だけの設定です。元の LR2 の設定ファイルの隣にあります。

`LR2files/Config/openlr2-config.xml`

`LR2files/Config/config.xml` は、いつもの LR2 の項目にそのまま使います。このページの項目は `openlr2-config.xml` だけから読みます。

## 直す前に

- ゲームを終了してから直してください。終了時にこのファイルを保存し直すので、手で直した内容が上書きされることがあります。
- このファイルが無くても、ゲームは下の初期値で起動します。正常終了するとファイルが作られます。ファイルはあるのに XML を読めないときは、`Failed to read OpenLR2 config` を出して起動しません。
- 特に書いていない場合、`0` はオフ、`1` はオンです。
- 行が無いときは、下に書いた初期値を使います。
- タグの名前は変えないでください。タグの間の値だけを変えます。
- 文字コードは Shift_JIS です。パスに日本語、韓国語、中国語があるときは、ゲームの中で選んでから終了し、ゲームに保存させる方が安全です。

## system

### resolution

スキンが自分のサイズを書いていないときの画面サイズです。スキンファイルに `#RESOLUTION` がある画面はスキンに書いたサイズを使い、この値はそのときの初期サイズです。

| 値 | サイズ | 名前 |
| --- | --- | --- |
| 0 | 640×480 | SD |
| 1 | 1280×720 | HD |
| 2 | 1920×1080 | Full HD |

1 と 2 以外の数字は 640×480 で表示します。ファイルに書いた数字は 0 に変えず、ゲームを終了しても同じ数字を書き戻します。SD のサイズは、数字をピクセルに変えるときだけ使います。`1` は 1280×720、`2` は 1920×1080、それ以外はすべて 640×480 です。

### fullscreenfilter

画面いっぱいに拡大するとき、絵をどうなめらかにするかです。

| 値 | 見た目 |
| --- | --- |
| 0 | なめらか（bilinear） |
| 1 | ドットをくっきり（nearest） |
| 2 | CRT |

### fullscreenfitstretch

絵の比率とモニターの比率が違うときの扱いです。

| 値 | 結果 |
| --- | --- |
| 0 | 絵の比率を保ちます。左右か上下に余白が出ることがあります。 |
| 1 | 画面いっぱいに引き伸ばします。横や縦に伸びて見えることがあります。 |

### screenmode

ゲームをどのウィンドウで開くかです。`config.xml` の `screenmode` は使いません。OpenLR2 はこのファイルの `screenmode` を使います。

| 値 | 結果 |
| --- | --- |
| 0 | フルスクリーン |
| 1 | ウィンドウ |
| 2 | 枠なしフルスクリーン（モニターを覆う、枠の無いウィンドウ） |

ファイルを読むとき、0 より小さいか 2 より大きい数字はメモリ上で 0 に置き換えます。正常終了するとファイルにも `0` が保存されます。`0` はモニターの現在のモードで開くフルスクリーンです。`1` はウィンドウです。`2` は枠が無くモニターを覆うウィンドウです。`0` と `2` はどちらもフルスクリーンで、フルスクリーンの方式だけが違います。この置き換えはファイルを読むときに行い、ウィンドウモードを適用する前です。ウィンドウモードを適用する関数は範囲外の数字を枠なしフルスクリーンとして扱いますが、このファイルから読んだ値は範囲外のままそこへ渡りません。

## play

### gaugeautoshift

ゲージ自動変更（GAS）です。選曲画面のオプションからもオンにでき、その選択はここに保存されます。

| 値 | 結果 |
| --- | --- |
| 0 | オフ。選んだゲージのままです。 |
| 1 | オン。そのゲージでは失敗するときは、まだクリアできているより易しいゲージに移します。 |

G-ATTACK はそのままです。

### newrandomrestart

リザルト画面で白鍵と青鍵を一緒に押していると、曲をやり直します。そのときのノーツ順を決めます。

| 値 | 結果 |
| --- | --- |
| 0 | ノーツ順はそのままです。 |
| 1 | 2番キー（青鍵）はノーツを混ぜ直します。他の青鍵は同じ順のままです。 |

プレイ中のやり直し（Start と Select を一緒に押したあと、Start は新しい順、Select は同じ順）とは別です。

この行が無いときの初期値は 0（オフ）です。

### lifttype

リフトのオンとオフです。リフトはノーツと判定ラインを上に動かします。判定の時間は変わりません。

| 値 | 結果 |
| --- | --- |
| 0 | オフ。下の `lift` の数字は効きません。 |
| 1 | オン。 |

0 以外の数字はすべて 1 として扱います。1P と 2P は開始時に同じ設定です。

### lift

ノーツと判定ラインをどれだけ上げるかです。0 から 100 までです。0 は元の位置、100 はいちばん上です。見た目の位置だけが変わります。

1P と 2P はこの数字で始まります。バトル中はプレイしながら左右を別々に変えられますが、次の起動で覚えているのは 1P の数字だけです。

## skin

### courseresult

コースリザルト画面で使うスキンファイルのパスです。選曲、プレイ、通常リザルトなどの他のスキンは `config.xml` にあります。元の LR2 にはこのスキン欄が無いので、OpenLR2 はここに置いています。

まだ選んでいなければ空のままにします。

## network

### display_ir

選曲画面とリザルト画面に出すインターネットランキングの名前です。`LR2files/CustomIRs` の中のフォルダ名と一致している必要があります。

空にすると、いつもの LR2 のランキング表示のままです。フォルダ名と合わないときは、そのランキングは出ません。

## 例

```xml
<?xml version="1.0" encoding="shift_jis"?>
<config>
	<system>
		<resolution>0</resolution>
		<fullscreenfilter>0</fullscreenfilter>
		<fullscreenfitstretch>0</fullscreenfitstretch>
		<screenmode>1</screenmode>
	</system>
	<play>
		<gaugeautoshift>0</gaugeautoshift>
		<newrandomrestart>0</newrandomrestart>
		<lifttype>0</lifttype>
		<lift>0</lift>
	</play>
	<skin>
		<courseresult></courseresult>
	</skin>
	<network>
		<display_ir></display_ir>
	</network>
</config>
```
